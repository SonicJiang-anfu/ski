# 雪坡大冒險（SKI DASH）

《數讀房市》預告片 STAGE 05 滑雪場景改成的網頁小遊戲。選一張地圖、從 11 位 Echo Forest 動物夥伴中選一位，一路滑到終點：閃障礙、跳、蹲、撿金幣，衝過終點後結算分數。

## 地圖

三個難度：新手三張、困難五張、地獄一張。每張地圖都有自己的賽道、畫面、專屬玩法、8-bit 音樂和音效；還沒做好的地圖會在選單上顯示「製作中」。

| 難度 | 地圖 | 狀態 |
|---|---|---|
| 新手 | 經典雪坡、水上樂園、大漠沙丘 | 全部完成 ✔ |
| 困難 | 叢林急流、玩具工廠、深夜街道、火山熔岩、賽博龐克 | 全部完成 ✔ |
| 地獄 | 數讀房市 | 完成 ✔ |

- **經典雪坡**：預告片原本的雪道。雪人只能繞過，石頭、柵欄要跳，低旗門要蹲；擦到兩側雪牆會減速。音樂是明亮的 D 大調 8-bit 進行曲（150 BPM）
- **水上樂園**：架在半空中的 U 型滑水道，旁邊的樂園有傾倒水桶塔（每 10 秒倒一次水）、螺旋滑水道塔、高速直落滑道、浪池、蘑菇噴泉和高大的椰子樹。彎道一個接一個、還有持續很久的長彎和大迴旋：彎越急越會把人甩上外側管壁，衝上去再滑下來；管壁高處有金幣，獎勵敢騎上牆的人。第四段是封閉的水管隧道，看不到天空，只有一圈圈燈帶，出口透進亮光。發光的藍色箭頭是加速水流，踩到會喊「加速！」、畫面兩側發藍光。泳圈可以跳或繞，巨型小鴨和紅鶴只能繞，浮標繩要跳（或騎在管壁高處越過），噴水管要蹲。五個路段的管子各是一種顏色，終點衝進大泳池。音樂是鋼鼓卡利普索（F 大調、140 BPM），音效換成水花、氣泡、塑膠管壁的摩擦聲
- **大漠沙丘**：午後的金黃沙漠，滑沙前進。整條賽道在沙丘上起伏，衝過丘頂會自然飛起來，空中排著金幣；賽道上有會轉的流沙漩渦，踩進去會大幅減速（可以繞開或跳過）；風滾草會在賽道上左右來回滾動，要抓時機跳過；第四段直直滑進大金字塔，裡面是點著火把、刻著圖紋的石頭通道，從另一頭的亮光出來。陶罐可以跳或繞，仙人掌只能繞，矮石牆要跳，條紋遮陽布要蹲；兩側是會減速的沙堤。四周有沙丘、綠洲（水塘、椰子樹、帳篷）、方尖碑、古代石柱、駱駝商隊、仙人掌、遠方的金字塔和熱氣球；最後一段颳起風沙。音樂是東方音階的弄蛇人風（D 調、128 BPM，陶鼓 maqsum 節奏加指鈸），音效換成沙子落地、揚沙、陷進流沙的咕嚕聲
- **叢林急流**（困難）：在雨林峽谷的激流上滑水，速度比新手地圖快。河面上有發亮、帶白色箭頭的**急流帶**，順著它滑會被水流推到平常到不了的極速；**鱷魚**有的會游過河道、有的會潛下水再浮上來（冒泡就是快浮起來了，潛在水裡時可以直接滑過）；第三段是連續**三道瀑布**，衝過瀑布邊緣會飛下去，空中排著金幣；第四段河道收窄成一條架在百公尺深峽谷上空、彎來彎去的**古代石造水道，兩邊沒有牆**，滑出邊緣或掉進水道的**斷口**就會掉下去（斷口前會有白色水花提醒：要跳）；掉下去後會放回水道正中間，短時間內邊緣會擋住她，也不會放在斷口前，所以不會一復活就又掉下去；水道盡頭接一道**垂直瀑布**：角色貼著水壁直直往下衝，速度飆到平常的兩倍多，鏡頭轉成從她頭頂往下拍，底下的整片樹冠海迎面衝上來，水壁上和瀑布下方沒有障礙物，只要左右移動吃金幣、享受速度；接著穿過**瀑布後面的洞窟**（右邊是一整面水簾），出洞後從**大瀑布**一躍而下，空中會進入**慢動作**、上下出現電影黑邊，落進彩虹下的瀉湖；河流接著衝進一座**巨大石像的嘴裡**，進入**古代神殿**：躲開輪流砸下的**石柱機關**，背後的牆突然被撞破，**一顆巨石滾出來追她**（鏡頭整個轉過去看巨石追來，踩加速帶逃命），神殿裡再分兩路（左邊蹲過**飛箭**、跳過**尖刺滾木**，右邊跳過**塌陷的地洞**），衝出神殿是懸崖，**抓住藤蔓盪過峽谷**（慢動作），落地後衝向終點。第二段的長彎後，河流繞著一座**河中小島分岔**：左邊是急流，有**岩石跳台**可以飛，還能**踩在一排鱷魚背上彈跳**；右邊鑽進一棵**倒下的巨大空心樹幹**，蹲過樹根、閃大蘑菇，金幣較多。長滿青苔的大石頭只能繞，漂流木要跳，低垂的樹枝、藤蔓石拱門和鐘乳石要蹲；兩側是會減速的岩石河岸。兩岸是一層層濃密的雨林（灌木層、樹冠層、伸到河面上的大樹），還有香蕉樹、竹林、蕨類、古老石像頭、遺跡石柱、巨嘴鳥、鸚鵡，瀉湖邊有高腳茅屋、獨木舟和火把；遠方是雲霧繚繞的石灰岩山峰。音樂是木琴加木鼓的叢林冒險風（A 多利安調式、152 BPM，偶爾有鳥叫），音效有水花、鱷魚咬合、掉落的長哨音、急流的水聲和慢動作時的瀑布轟鳴
- **玩具工廠**（困難）：從組裝線一路滑到出貨口的玩具工廠。**側向輸送帶**把人往旁邊推（黃色箭頭標示方向）；**沖壓機**一排排輪流砸下來，紅燈閃就是快砸了，可以趁抬起時鑽過，也可以走空出來的那一道；機械手臂要蹲。**分揀機**把產線分成兩邊：左邊是滿是輸送帶和沖壓機的高架走道，右邊下到噴漆室，閃彈珠和錫兵。**球池**踩彈跳床彈過去，連續彈跳每一張都偏得更遠，要在空中對準下一張；超級彈跳床飛過氣球。接著衝進一台**巨大的電視機**，畫面瞬間變成 **2D 橫向卷軸遊戲**（側面視角、映像管掃描線和外框、配樂換成紅白機風格）：這一段她會用固定速度自己往前跑（← → 不作用），要跳過或**踩扁**走過來的發條機器人（踩到會彈起來）、跳過深坑和尖刺、碾壓機在她跑到時砸下來、停在頭頂上，要**蹲**著鑽過、蹲過橫桿、踩大彈簧飛過長坑；最後撞破螢幕**回到現實**。組裝產線中段左右繞過一疊疊等著裝箱的**積木塔和泰迪熊**、跳過禮物。最後一段是架在高腳上的**橘色玩具賽車軌道**：發條小賽車、長彎道、加速帶、**飛越斷軌**、**垂直大迴環**（鏡頭跟著翻轉一圈），緊接著像玩具軌道那樣的**螺旋翻轉**（整座工廠大廳繞著她轉一圈，裡面沒有障礙物），賽車道中段還會被**分隔牆分成兩線**（左線加速帶接力、右線閃發條賽車再飛小跳台），衝過巨大禮物盒（GOAL 出貨！）。音樂是音樂盒加木琴的發條玩具進行曲（G 大調、144 BPM），電視裡換成同一首歌的 8-bit 版本
- **深夜街道**（困難）：午夜的城市，一路往下坡滑。**逆向來車**開著大燈直衝過來，撞上前一秒會按喇叭，從旁邊擦身而過會有「咻」的一聲。路上有好幾個**岔路**，中間有分隔島擋著，兩邊各是不同的路線：第一段左邊是**夜市小巷**（攤位、紅燈籠要蹲），右邊是馬路（計程車迎面而來）；高速公路上左邊是**逆向車流加速帶**，右邊是**施工區**（要跳過壕溝）；交流道左邊爬上**高架橋**（金幣多、看得到城市夜景），右邊鑽進**霓虹隧道**（加速帶、燈光飛逝）。最後衝上一座沒蓋完的**斷頭高架橋**，盡頭的發射台把她**甩上夜空**（慢動作），降落在一架正在進場的**巨無霸客機背上**，沿著機身、越過機翼滑到機頭，再從機頭往下俯衝，**直接撞破摩天大樓的玻璃帷幕**（大樓外觀每扇窗都一樣，沒有事先開口），衝進辦公室：加班的動物們（其他可選角色）嚇得跳起來、頭上冒驚嘆號、文件亂飛；辦公椅會滑來滑去，隔板要繞、紙箱要跳、天花板吊牌要蹲。再撞破另一面玻璃跳到屋頂（冷氣機、水塔、曬衣繩），一路跳回街上，在煙火下衝過終點。音樂是 8-bit 合成器流行風（A 小調、136 BPM、四拍大鼓），音效有喇叭、擦身咻聲、起飛、玻璃碎裂、動物驚叫
- **火山熔岩**（困難）：從一座活火山上滑下去，再從另一邊逃出來。一開始路就繞著一道岩脊**分岔**：左邊是一整排**蒸氣噴口**，從一個彈到下一個，飛過底下的岩漿原；右邊是一道**岩漿急流**可以衝浪，**熔岩球**左右滾過來要跳（火山內部的岩漿洞窟也有一樣的二選一：左邊連跳岩漿池，右邊衝岩漿急流）。黑色火山渣坡上有**橫越賽道的岩漿溝**要跳（有些前面有小跳台可以飛過去，金幣沿著飛行路線排）；天上掉下**火山彈**，地上會先出現紅色落點圈，她靠近時火山彈就砸在圈上；接著是兩邊沒有護欄、底下就是岩漿湖的**火口稜線**。進入火山口後路分兩邊：左邊鑽進低矮的**熔岩管**（垂下來的發光鐘乳石要蹲、玄武岩柱要閃），右邊是一排排輪流噴發的**岩漿噴泉**（冒泡就是快噴了）；匯合後還有一整片噴泉像浪一樣輪流噴。然後坐上**礦車**衝進硫磺礦坑：三條軌道，← → 一次換一條軌，躲路障、跳過斷掉的軌道、閃開迎面衝來的失控礦車（坐在車上，不會有要蹲的障礙），最後礦車從軌道盡頭**飛出礦坑、越過岩漿谷**。接著在**熔岩湖**上一座一座小島跳過去（兩邊沒有護欄），中途的**蒸氣噴口**把她噴過最寬的一段。最後一座小島開始震動，後面的缺口看起來和前面的一樣、對岸的小島也近在眼前，**其實根本跳不過去**：她掉下去，穿破岩漿表面，**墜入火山口**（慢動作），掉進火山內部的**岩漿洞窟**：兩側是岩漿河，頂上垂著鐘乳石，要閃岩漿噴泉、跳過岩漿池、蹲過垂下的岩石。洞窟盡頭**火山爆發**，她被岩漿柱從**山腰的洞口噴出去**：慢動作，鏡頭整個轉過去看身後的山壁噴出岩漿、山頂火山正在爆發，落地後一路逃下外側山坡，火山彈像雨一樣落下，中途再分兩路（左邊閃火山彈、右邊跳過裂開的岩漿），衝過連續加速帶，終點是山腳的**溫泉鄉**。音樂是 8-bit 重搖滾（A 小調、160 BPM、強力和弦），進礦坑換成加了鐵鎚敲擊聲的快版，火山爆發時換成副歌高潮版；音效有火山彈呼嘯落地、礦車換軌喀啦聲、蒸氣噴發、火山爆發的轟隆聲
- **賽博龐克**（困難，英文名 NEON OVERDRIVE）：下著雨的霓虹巨型都市，踩著反重力滑板往下衝，速度是困難地圖裡最快的。第一段**霓虹大道**：**全息投影牆**會不定時閃滅（熄掉時可以直接穿過），紅色**雷射掃描條**貼地左右掃（要跳），**警用無人機**扛著橫桿迎面俯衝（要蹲），地上有會推著人加速的**光速車道**；路在販賣機亭前分岔（左邊上**磁浮高架**：長光速車道、雷射和無人機；右邊下到有屋頂的**地下商場**：全息牆、低垂招牌、金幣多），接著是一長段持續彎道上輪流發射的**雷射門**。第二段**飛簷走壁**：衝上沒有護欄的**磁浮天軌**（掉出邊緣或斷口就會掉下去），接著整條軌道**扭轉 90° 貼上摩天大樓的玻璃帷幕**，她在大樓牆面上滑（冷氣機要跳、擦窗吊籃要繞、清潔繩要蹲），飛過兩棟大樓中間的巷子，再轉回來；然後衝進**螺旋光環隧道**，軌道連轉兩圈，整座城市繞著她旋轉（隧道裡沒有障礙物，只有光速車道和金幣，專心享受）。第三段**倒懸都市**：軌道翻過來，她**倒掛在空中巨構底下**滑，真正的城市懸在頭頂，招牌字是倒的，雨往上落；要跳或踩扁維修機器人、閃輪流吹的排氣扇、蹲過管線，斷口掉下去會「**掉進天空**」。第四段**超頻衝撞**：穿過 OVERDRIVE 大門進入**超頻模式**，速度暴增、整個畫面燒成洋紅和黃色，擋路的警察機器人、木箱、拒馬、懸浮車、全息牆、無人機**全部一撞就飛**，畫面中央跳出「粉碎！×N」連擊數；出來後再分岔（左邊快線加雷射、右邊隧道加無人機）。第五段**數據終點**：**數據方塊橋**從四面八方飛過來、就在她前方即時拼成路（中間有斷口要跳），最後從橋頭彈射升空、**慢動作加 360° 空中翻滾，直接穿過一尊高樓那麼大的全息投影（投影的是玩家自己選的角色）**（畫面跟著故障閃爍），落在廣場上，Echo Forest 的動物們在兩旁歡呼，衝過霓虹終點門。四周有密集的霓虹大樓（直立招牌：拉麵、電玩、旅館…）、全息廣告（錦鯉、貓臉、水母、「不夜城」）、空中車流、遠方的巨塔和切成條紋的霓虹太陽。音樂是 8-bit 合成器浪潮（synthwave，E 小調、128 BPM，十六分音符八度貝斯、閘門軍鼓），上天軌換成飄浮版、超頻時換成 150 BPM 的四拍大鼓版；音效有磁浮啟動、軌道扭轉的呼嘯、無人機旋翼、粉碎爆裂、數據組裝的嗶聲、全息故障聲
- **數讀房市**（地獄，英文名 HOUSING DECODER）：另一個次元，不是雪也不是山：黑色虛空裡用光線畫出來的數據空間，線條和光圈跟著音樂的拍子閃動，她踩著會拖出光軌的板子。最高速比困難快一點，難在操作和讀畫面。1 條岔路，整趟約 107 秒。
  - **漲跌曲線**：一開場就是一條虛構房價指數做成的光帶，沒有護欄（掉出去就「掉出圖表」），有上坡也有從高點飛出去的陡降；成交價看板要跳、地圖圖釘要繞、資料點上下彈、價格牌左右滑，資料斷層要跳。分岔：左邊衝上房價山脊從發射台飛越（慢動作）／右邊鑽進跌價山谷蹲過綠色下跌箭頭。最後指數崩盤，她跟著垂直墜落（「房價崩盤！」）。
  - **時光倒流**：從跳台被拋上半空，慢動作裡鏡頭繞著她轉半圈（像火山噴發那段），落地時已經是倒退滑；前方只能從貓頭鷹舉著的後照鏡裡看到。鏡子是**反向後照鏡**：鏡中的畫面左右沒有翻轉，所以按 ← → 時她在鏡中往相反方向移動，鏡中的她本身則是鏡像（從她身後高處往下看，她蹲下時鏡中也蹲）。轉身時畫面只跳出「反向鏡」三個字，鏡子下緣也一直掛著「反向鏡」標籤；轉回正面時不顯示說明。從正面看到的她（鏡中、網站俯視、終點鏡頭）都是拿著雪杖的正面滑雪圖。跑道是一條兩側沒有牆的底片（左右相反時很容易滑出去掉下去），年份從 2025 往回數，畫面越來越泛黃，音樂也倒著播；最後再被拋起一次，鏡頭轉回來。
  - **數據隧道**：轉回來後衝進一根 360° 的數據管道（參考 Tunnel Rush、Tempest），← → 是繞著管壁轉，可以滑上牆、滑過頭頂，整個世界繞著她旋轉；數據方塊要跳、紅色防火牆擋住一部分管壁要從另一邊繞（甚至從天花板繞過去）、掃描刀片繞著管子掃、尖刺一伸一縮，金幣繞成螺旋。出隧道時不管她在管壁哪裡，都會被自動導回正中央。
  - **網站衝浪**：出隧道後鏡頭升到她正上方、轉半圈，虛空淡掉，整個畫面變成**真正的數讀房市網站**：就像平常在瀏覽網頁一樣，網頁跟著她往下捲（置頂導覽列、右下角的聊天鈕都是網站自己的），只是畫面上多了她、金幣和障礙物。橫式顯示桌機版：首頁 → 視覺化圖表 → 一篇文章（〈919 前，房價漲贏成本；919 後，成本反超房價〉）；直式顯示手機版：文章列表 → 視覺化圖表 → 同一篇文章。滑過頁面上的「前往○○ →」連結就是點下去，換到下一頁（滑鼠點擊聲、頂端的載入進度條）。障礙物是瀏覽網頁時會突然冒出來的東西：訂閱週報／登入／允許通知的彈出視窗（要繞）、橫跨整頁只留一個缺口的 Cookie 提示列（從缺口穿過）、左右滑動的「已加入收藏」通知和滑鼠游標（要跳）、時有時無的載入圈（跳過，或等它消失）。這一段速度放慢到瀏覽的節奏（限速 11），橫式畫面裡角色縮小到 75%（直式本來就小，不縮），俯視時 ← → 照畫面方向。網頁是用 `tools/sitesnap.js` 從網站實際渲染後存下來的 HTML、CSS、圖片和字型（`assets/site/`），遊戲裡由瀏覽器照網站自己的排版顯示，不連網也能玩。
  - **光環衝刺**：從噴射台以極快的速度射出（約平常最高速的兩倍多），射進一串空中加速光環（參考 Sonic），前三個環距離很遠，之後連續一個接一個；每個環的位置左右高低都不同，接住她就往自己的方向把她噴到下一個環，全程不用操作，畫面每穿過一環就往外一沖，伴隨噴射音效。最後落在下方的長坡上。接著「複製貼上！」：畫面上多出三個一模一樣的她（一個左右和她相反、兩個晚半拍），鏡頭不再把她放在中間、也不顯示她的滑行痕跡和吃金幣的分數，玩家要自己認出哪個是自己。再來「走在走勢線上！」：走勢線細到只剩一條，沒有護欄、急彎一個接一個、還會上下起伏，沒有障礙物（滑雪板真的離開線才會掉）。最後「暴漲！」加速帶首尾相接，而且越後面越快（加速帶的最高速沿路從約 44 一路拉到 88，和噴射台一樣快）衝進終點，看台上的動物們歡呼。
  - 音樂是 8-bit 數據流行樂（F 大調，八音盒琶音、時鐘滴答當 hi-hat）：隧道裡是 164 BPM 全力版、光帶上 140 BPM、倒退時整首倒著播、網站上是乾淨明亮的 140 BPM 版、光環開始是 156 BPM 衝刺版。音效有衝進隧道、進入網站（滑鼠點擊＋翻頁）、點連結換頁、噴射、拋起轉身、穿過光環、錄音帶倒帶、複製貼上、落下的數字。

## 怎麼玩

- **流程**：首頁 → 選角色 → 選地圖 → 角色出場說「會贏喔！」（約 1.2 秒）→ 倒數 → 滑雪 → 結算。選地圖卡片右上角的獎牌是那張地圖拿過的最高評級（S 級會閃光）。角色只差在外觀，能力都一樣；遊戲會記住上次選的角色；選地圖畫面一律從經典雪坡開始
- **選角**：方向鍵或滑鼠／點擊選角色，Enter 或「下一步」到選地圖，Esc 回首頁
- **選地圖**：卡片橫向排成一列，每張卡片是那張地圖的遊玩畫面、難度、名稱和最高分；← → 換卡片（↑ ↓ 也可以；按住 ← → 會連續切換，放開後背景才換成停下來的那張地圖），Enter 出發；手機、平板用手指左右滑動換卡片（卡片會跟著手指移動），點旁邊的卡片會把它移到中間，要按「出發」按鈕才會進入（點中間的卡片不會出發，避免滑動時誤觸）；滑鼠點中間的卡片或按「出發」都可以出發，也可以點兩側的 ◀ ▶。卡片下方的小方塊標出目前在哪個難度、第幾張。Esc 回選角。背景會播放剛選的角色滑目前選到的地圖
- **電腦**：← → 轉彎閃避、↑ 跳躍（空白鍵也可以）、↓ 蹲下、Esc／P 暫停、M 靜音
- **暫停選單**：繼續、重新開始、回到首頁（↑ ↓ 選擇、Enter／空白鍵確定；Esc 直接繼續）；**結算畫面**：再玩一次、回到首頁（← → 選擇、Enter／空白鍵確定；Esc 直接回首頁）
- **手機、平板**：左下 ◀ ▶ 轉彎、右下 JUMP 跳躍、DUCK 蹲下；直拿、橫拿都能玩，會自動切換版面
- **終點觀眾**：每張地圖的終點兩旁都有其他 Echo Forest 動物站在看台上歡呼（看台依地圖主題：雪地木台、池畔、砂岩台階、竹台、玩具積木、街邊看台、溫泉鄉木台、霓虹廣場）
- **撞到障礙物**：跌倒後退回約 3 秒前的位置，計時不會停
- **彎道**：會把人往外甩，要按住方向鍵才轉得過去
- **沒有牆的地方**（困難以上）：滑出邊緣或掉進斷口會「掉下去了！」，一樣退回約 3 秒前、計時不停
- **計分**：時間分 = (標準時間 − 抵達秒數) × 100，金幣每枚 50 分
  - 標準時間：經典雪坡 120 秒、水上樂園 106 秒、大漠沙丘 111 秒、叢林急流 108 秒、深夜街道 118 秒、玩具工廠 122 秒、火山熔岩 127 秒、賽博龐克 109 秒、數讀房市 160 秒（讓各張圖的分數差不多）
  - 評等：S ≥ 8,500、A ≥ 7,000、B ≥ 5,000，其餘是 C
  - 每張地圖各自記最高分，存在這台裝置的瀏覽器裡

每張地圖分成五段（新手約 1,500 公尺，叢林急流 1,942 公尺但速度更快）。自動駕駛一路不失誤：經典雪坡約 65 秒、9,200 分；水上樂園約 65 秒、9,200 分；大漠沙丘約 68 秒、9,250 分；叢林急流約 63 秒、9,150 分；深夜街道約 65 秒、9,040 分；玩具工廠約 78 秒、9,200 分；火山熔岩約 83 秒、9,160 分；賽博龐克約 63 秒、9,165 分；數讀房市約 107 秒、9,190 分。

`node tools/analyze.js` 會替每張地圖算出難度指數和好玩潛力指數（用完美路線和三種程度的模擬玩家實際跑出來），新做或修改地圖後可以拿來比較。

## 放上網路分享

整個資料夾都是靜態檔案，不需要伺服器程式，也不需要建置。上傳時**只需要**這些：

```
index.html
js/
assets/
```

`docs/`、`tests/`、`tools/` 是開發用的，不用上傳。

目前已經放在 GitHub Pages：**https://sonicjiang-anfu.github.io/ski/**（更新方式見 `docs/交接.md` 0.1 節）。

### GitHub Pages（免費、網址固定）
1. 在 GitHub 建立一個新的 repository，例如 `anje-ski`
2. 把上面三樣東西上傳到 repository 的根目錄（網頁上可以直接拖曳上傳）
3. 到 repository 的 **Settings → Pages**，Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`，按 Save
4. 等一兩分鐘，網址會是 `https://你的帳號.github.io/anje-ski/`

### itch.io（網頁遊戲平台）
1. 把 `index.html`、`js/`、`assets/` 壓成一個 zip（`index.html` 要在 zip 的最上層）
2. 在 itch.io 建立新專案，Kind of project 選 **HTML**，上傳 zip，勾選 **This file will be played in the browser**
3. Viewport 建議設成 1280 × 720，並勾選 **Mobile friendly** 和 **Fullscreen button**

## 開發

接手開發新地圖前，先讀 `docs/交接.md`（規則、架構、做新地圖的步驟、踩過的坑）。

| 指令 | 用途 |
|---|---|
| `node --test tests/*.test.js` | 單元測試：每張地圖的賽道、物理、計分，以及自動駕駛跑完每張地圖 |
| `node tools/botrun.js [water]` | 印出自動駕駛在某張地圖的跑法：各段時間、跌倒位置、金幣數 |
| `node tools/playtest.js` | 在無頭 Chrome 裡用鍵盤和觸控實際操作一輪 |
| `node tools/shot.js [title,play,...]` | 截圖到 `tools/out/`（橫式、直式、各區段、各畫面） |
| `node tools/mapshots.js [snow,...]` | 重新拍選地圖卡片上的遊玩畫面（`assets/maps/*.jpg`） |
| `node tools/analyze.js [ids]` | 每張地圖的難度指數、好玩潛力指數和各項數據 |
| `node tools/skill.js volcano` | 模擬高手、一般、新手三種程度的玩家，列出各自撞在哪裡 |
| `node tools/zshots.js 名稱 volcano 40:20 360:30` | 在指定位置各拍一張截圖（`python tools/grid.py 名稱` 拼成一張） |
| `node tools/coinmiss.js cyber` | 列出自動駕駛沒吃到的金幣（位置、高度），排金幣時用 |
| `node tools/themeprof.js cyber 1300` | 在降速的 CPU 下量某個位置每一格畫面花在外觀的哪個部分（天空、路面、障礙物…） |
| `node tools/music.js` | 把 BGM 和音效離線算成 WAV 到 `tools/out/`，方便試聽 |
| `node tools/perf.js 4 [water]` | 在 4 倍慢的 CPU 下量每格的繪製時間 |
| `python tools/sprites_ski.py` | 重新產生 11 位角色的滑雪背影圖，並複製正面圖到 `assets/sprites/`（預覽在 `tools/out/ski_sheet.png`） |
| `node tools/polycount.js 600` | 數某個位置一格畫了多少多邊形（依來源分類） |
| `node tools/filecheck.js` | 確認直接雙擊開啟（`file://`）時字型、圖片都正常 |
| `node tools/ringsolve.js '[[1,0,7],…]'` | 設計空中光環連彈：給每個環的位置，解出每次拋出的速度（數讀房市的 `RTHROW`） |
| `node tools/sitesnap.js` | 重新存下數讀房市網站的頁面（網站內容更新後跑一次；存到 `assets/site/`） |
| `node tools/pagescheck.js [網址]` | 上線前檢查（照 GitHub Pages 分大小寫的規則載入）；給網址就檢查線上版 |
| `node tools/sitecheck.js home 0,1500 [portrait]` | 比對遊戲裡顯示的網站頁面和真正的網站（同一個捲動位置各拍一張） |

網址參數（除錯用）：`?state=play&z=600` 直接從指定位置開始、`&map=water` 指定地圖、`?state=maps` 直接進選地圖、`?state=select` 直接進選角、`&char=anleo` 指定角色、`&bot` 自動駕駛、`&touch` 強制顯示觸控按鈕、`&portrait` 強制直式。

工具需要 Node 22。puppeteer 沿用隔壁 `housing-decoder-game-video/node_modules`，Chrome 的路徑可以用 `CHROME` 環境變數覆寫。

程式結構：
- `js/maps.js`：九張地圖的清單（難度、名稱）
- `js/maps/<地圖>.js`：一張地圖一個檔案，裡面有賽道（彎道、坡度、障礙物、金幣）、畫面（天空、場景、障礙物的樣子）、這張地圖的物理差異、音樂和計分規則
- `js/course.js`：把地圖資料組成賽道（也負責 U 型滑道的斷面、會變窄的路段、沒有牆的路段、急流帶、斷口和垂直滑下的峭壁）
- `js/world.js`：3D 畫面引擎（攝影機、排序、金幣、跳台、加速板、急流帶、角色）
- `js/audio.js`：所有 BGM 和音效

想調整難度或手感：共用的物理常數在 `js/physics.js` 的 `K`，各地圖的差異寫在該地圖檔案的 `phys`。
改完跑一次 `node --test tests/*.test.js`，確認自動駕駛還能不失誤跑完每張地圖。

新增地圖：照 `js/maps/water.js` 的格式寫一個新檔案，在 `index.html` 加一行 `<script>`，地圖就會出現在選單上（測試也會自動檢查它）。
